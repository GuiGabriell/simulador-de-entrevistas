# Estudos em Ciência de Dados - Roadmap 200 Dias

Este repositório documenta minha jornada de **200 dias de estudos** em Ciência de Dados, com foco em Python, SQL, Power BI, Inteligência Artificial e GitHub.

## 🎯 Objetivo
Construir uma base sólida em ciência de dados, desenvolver projetos práticos e preparar um portfólio profissional para entrevistas e oportunidades na área.

## 📂 Estrutura
- `fundamentos/` → Python, SQL e Estatística
- `powerbi/` → Dashboards e relatórios
- `ia/` → Projetos de Machine Learning e IA
- `projetos/` → Projeto principal de Churn e outros
- `entrevistas/` → Preparação para entrevistas técnicas
- `roadmap.md` → Cronograma detalhado dos 200 dias

## 🚀 Cursos Utilizados
- Python: *Python 2026 - Completo do Zero ao Avançado* (Udemy)
- SQL: *SQL Academy - Banco de Dados do Zero ao Avançado* (Udemy)
- Power BI: *Power BI 2026: do Básico ao Avançado* (Udemy)
- IA: *Formação Inteligência Artificial: Do Zero ao Avançado* (Udemy) + *Google Cloud Arcade*

## 📈 Projeto de Portfólio
**Análise Preditiva de Churn**  
Pipeline completo: coleta de dados → limpeza → modelagem → dashboard → documentação no GitHub.
